📖 Introduction

Bienvenue dans la documentation de l'API v2 de Safari Smart Mobility. Cette API REST permet de gérer tous les aspects du système de transport.

Base URL: http://localhost/SafariSmartMobily/apiv2

Format des réponses

Toutes les réponses sont au format JSON avec la structure suivante:

{
    "success": true|false,
    "message": "Message descriptif",
    "data": { ... } // Pour les succès
    "errors": { ... } // Pour les erreurs de validation
}

Codes HTTP

  • 200 - Succès
  • 201 - Créé avec succès
  • 400 - Requête invalide
  • 404 - Ressource non trouvée
  • 422 - Erreur de validation
  • 500 - Erreur serveur

🚌 Bus

GET Obtenir tous les bus

/bus

Récupère la liste de tous les bus.

Exemple de réponse: 
{
    "success": true,
    "message": "Buses retrieved successfully",
    "data": [
        {
            "id": 1,
            "numero": "BUS001",
            "immatriculation": "CD-123-AB",
            "marque": "Mercedes",
            "modele": "Sprinter",
            "capacite": 50,
            "statut": "actif"
        }
    ]
}

GET Obtenir un bus

/bus/{id}

Récupère les détails d'un bus spécifique.

POST Créer un bus

/bus

Crée un nouveau bus.

Paramètres:
Champ Type Requis Description
numero string Oui Numéro du bus
immatriculation string Oui Plaque d'immatriculation
marque string Non Marque du bus
modele string Non Modèle du bus
capacite integer Non Capacité en passagers
statut enum Non actif, maintenance, panne, inactif

PUT Mettre à jour un bus

/bus/{id}

Met à jour les informations d'un bus.

DELETE Supprimer un bus

/bus/{id}

Supprime un bus.

💡 Exemples d'utilisation

Avec cURL

# GET - Obtenir tous les bus
curl http://localhost/SafariSmartMobily/apiv2/bus

# POST - Créer un bus
curl -X POST http://localhost/SafariSmartMobily/apiv2/bus \
  -H "Content-Type: application/json" \
  -d '{
    "numero": "BUS001",
    "immatriculation": "CD-123-AB",
    "marque": "Mercedes",
    "capacite": 50
  }'

# PUT - Mettre à jour un bus
curl -X PUT http://localhost/SafariSmartMobily/apiv2/bus/1 \
  -H "Content-Type: application/json" \
  -d '{"statut": "maintenance"}'

# DELETE - Supprimer un bus
curl -X DELETE http://localhost/SafariSmartMobily/apiv2/bus/1

Avec JavaScript (Fetch)

// GET
fetch('http://localhost/SafariSmartMobily/apiv2/bus')
  .then(response => response.json())
  .then(data => console.log(data));

// POST
fetch('http://localhost/SafariSmartMobily/apiv2/bus', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    numero: 'BUS001',
    immatriculation: 'CD-123-AB',
    marque: 'Mercedes',
    capacite: 50
  })
})
.then(response => response.json())
.then(data => console.log(data));
